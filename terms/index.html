Al acceder o usar FireDex (el «Servicio») aceptas estos Términos y condiciones. Si no estás de acuerdo, no uses el Servicio. Si eres menor de edad según la ley de tu país, debes usarlo con el permiso y la supervisión de tu madre, padre o tutor.

2. Qué es el Servicio

FireDex es un conjunto de herramientas web gratuitas para crear contenido de Minecraft Bedrock: editor de código, modelador 3D, animaciones, generador de manifest, comandos y guías. Todo el procesamiento ocurre en tu navegador; el Servicio no tiene cuentas de usuario ni envía tus proyectos a ningún servidor.

• Eres responsable de hacer copias de seguridad (botón Exportar). Borrar los datos del sitio, usar modo privado, cambiar de navegador o limpiar el almacenamiento puede eliminar tus proyectos de forma permanente.
• Debes tener los derechos necesarios sobre cualquier archivo que cargues (texturas, modelos, código, addons de terceros).
